# 1 Introduction

This specification defines the network format of native Windows
structures that can be used within other protocols. It also describes
the structure of common Windows native file system control codes, file
information levels, and file system information levels that are issued
in client/server and server/server communications. These structures do
not result in a protocol, but their structure is common across multiple
protocols. As such, they are placed in this document as a reference that
can be used by other protocols to ensure consistency and accuracy.

Sections 1.7 and 2 of this specification are normative. All other
sections and examples in this specification are informative.
