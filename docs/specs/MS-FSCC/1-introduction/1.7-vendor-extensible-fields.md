## 1.7 Vendor-Extensible Fields

File system control codes that are used to set [**reparse
point**](#gt_4fed0b53-5fc8-4818-886f-93d87f3035e1) data specify a
**ReparseTag** field value that identifies the file system
[**filter**](#gt_ffbe7b55-8e84-4f41-a18d-fc29191a4cda) that understands
the application-specific reparse point data format. A vendor developing
an application protocol that sets reparse point data MUST request a
unique reparse [**tag**](#gt_bfa52023-7248-4ab5-b889-6b53348a773b) for
that application from Microsoft by following the instructions described
in [\[WHDC-RPTR\]](https://go.microsoft.com/fwlink/?LinkId=90564). For
more information about reparse points, see
[\[REPARSE\]](https://go.microsoft.com/fwlink/?LinkId=90259).

This protocol uses NTSTATUS values, as specified in
[\[MS-ERREF\]](%5bMS-ERREF%5d.pdf#Section_1bc92ddfb79e413cbbaa99a5281a6c90).
Vendors are free to choose their own values for this field as long as
the C bit (0x20000000) is set, indicating it is a customer code.
