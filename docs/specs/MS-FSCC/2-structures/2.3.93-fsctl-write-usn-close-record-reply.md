### 2.3.93 FSCTL_WRITE_USN_CLOSE_RECORD Reply

This message returns the results of the [FSCTL_WRITE_USN_CLOSE_RECORD
request](#Section_059a4dea601f44a4b3687a7f5b668696) as a single field,
**Usn**, which is a 64-bit signed integer that contains the server file
system's [**USN**](#gt_01936446-8739-4b98-b83f-fb5e2a53ce4c) for the
file or directory. This value MUST be greater than or equal to 0.

This message returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is STATUS_SUCCESS.
