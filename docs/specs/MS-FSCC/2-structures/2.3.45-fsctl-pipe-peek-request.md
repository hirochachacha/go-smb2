### 2.3.45 FSCTL_PIPE_PEEK Request

The FSCTL_PIPE_PEEK request requests that the server copy a named pipe's
data into a buffer for preview without removing it. The FSCTL_PIPE_PEEK
request message is issued to invoke a reply, and does not have an
associated data structure.
