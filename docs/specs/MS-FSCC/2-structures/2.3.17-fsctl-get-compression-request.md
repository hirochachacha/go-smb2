### 2.3.17 FSCTL_GET_COMPRESSION Request

This message requests that the server return the current compression
state of the file or directory associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked.

This message does not contain any additional data elements.
