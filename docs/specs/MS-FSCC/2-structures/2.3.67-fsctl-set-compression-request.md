### 2.3.67 FSCTL_SET_COMPRESSION Request

The FSCTL_SET_COMPRESSION request message requests that the server set
the compression state of the file or directory associated with the
handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked. The
message contains a 16-bit unsigned integer.

values.

<td>The file or directory is not compressed.</td>

<tr>
<td><p>COMPRESSION_FORMAT_DEFAULT</p>
<p>0x0001</p></td>
<td>The file or directory is compressed by using the default compression

<p>0x0002</p></td>
<td>The file or directory is compressed by using the LZNT1 compression

<td>Reserved for future use and MUST NOT be used.</td>

The actual file or directory compression performed when a server
receives a request for COMPRESSION_FORMAT_DEFAULT and
COMPRESSION_FORMAT_LZNT1 is
implementation-dependent.<span id="Appendix_A_Target_63"
class="anchor"></span>[\<63\>](#Appendix_A_63)

If the file system of the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) containing the
specified file or directory does not support per-file or per-directory
compression, the request MUST NOT succeed. The error code returned in
this situation is specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7).
