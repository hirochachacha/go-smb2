### 2.3.3 FSCTL_DELETE_OBJECT_ID Request

This message requests that the server remove the object identifier from
the file or directory associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked. The
underlying object MUST NOT be deleted. If the file or directory has no
object identifier, the request MUST be considered successful.

This message does not contain any additional data elements.
