### 2.3.42 FSCTL_OFFLOAD_READ Reply

**Size (4 bytes):** A 32-bit unsigned integer that indicates the size,
in bytes, of the returned data element.

**Flags (4 bytes):** A 32-bit unsigned integer that indicates which
flags were returned for this operation. Possible values for the flags
follow. All unused bits are reserved for future use, SHOULD be set to 0,
and MUST be ignored.

<td><p>OFFLOAD_READ_FLAG_ALL_ZERO_BEYOND_CURRENT_RANGE</p>
<p>0x00000001</p></td>
<td>The data beyond the current range is logically equivalent to
zero.</td>
</tr>
</tbody>

**TransferLength (8 bytes):** A 64-bit unsigned integer that contains
the amount, in bytes, of data that the
[**Token**](#gt_95f17071-c8f1-403a-8a92-cf87aa7d40f5) logically
represents. This value indicates a contiguous region of the file from
the beginning of the requested offset in the **FileOffset** field in the
FSCTL_OFFLOAD_READ_INPUT data element (section 2.3.41). This value can
be smaller than the **CopyLength** field specified in the
FSCTL_OFFLOAD_READ_INPUT data element, which indicates that less data
was logically represented (logically read) with the Token than was
requested. The value of this field MUST be greater than
0x0000000000000000 and MUST be aligned to a logical sector boundary on
the [**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c).

**Token (512 bytes):** A [STORAGE_OFFLOAD_TOKEN (section
2.1.11)](#Section_b8d041b82cd84ee0910c715c6449e372) structure that
contains the generated Token to be used as a representation of the data
contained within the portion of the file specified in the
FSCTL_OFFLOAD_READ_INPUT data element at the time of the
FSCTL_OFFLOAD_READ operation. The contents of this field MUST NOT be
modified during subsequent operations.<span id="Appendix_A_Target_39"
class="anchor"></span>[\<39\>](#Appendix_A_39)

This message returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is STATUS_SUCCESS.
