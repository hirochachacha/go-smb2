### 2.3.91 FSCTL_VIRTUAL_STORAGE_QUERY_PROPERTY Request

This request contains a message with the same structure as the
IOCTL_STORAGE_QUERY_PROPERTY request (section
[2.8.1](#Section_02c896910a2e4e6c8d1e32c781406397)) with the following
values:

**PropertyId** **(4 bytes)**: 0x00000004

**QueryType** **(4 bytes)**: 0x00000000

Remote servers SHOULD ignore this
request.<span id="Appendix_A_Target_86"
class="anchor"></span>[\<86\>](#Appendix_A_86)
