**DeletePending (1 byte):** An 8-bit field that is set to 1 to indicate
that a file SHOULD be deleted when it is closed; otherwise, 0 which
means the file SHOULD NOT be deleted.<span id="Appendix_A_Target_114"
class="anchor"></span>[\<114\>](#Appendix_A_114)

For a discussion of file deletion semantics, see
[\[FSBO\]](https://go.microsoft.com/fwlink/?LinkId=140636).

This operation returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this file
information class is STATUS_SUCCESS. The most common error codes are
listed in the following table.
