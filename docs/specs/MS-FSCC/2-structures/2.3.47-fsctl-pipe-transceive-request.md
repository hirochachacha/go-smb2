### 2.3.47 FSCTL_PIPE_TRANSCEIVE Request

The FSCTL_PIPE_TRANSCEIVE request is used to send and receive data from
an open pipe. Any bytes in the FSCTL input buffer are written as a
[**binary large object
(BLOB)**](#gt_ad861812-8cb0-497a-80bb-13c95aa4e425) to the input buffer
of the pipe server.

The FSCTL input buffer does not have an associated structure. The buffer
is a BLOB of bytes that are written into the associated pipe.
