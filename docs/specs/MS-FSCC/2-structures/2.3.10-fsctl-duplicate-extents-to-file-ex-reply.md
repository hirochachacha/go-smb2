### 2.3.10 FSCTL_DUPLICATE_EXTENTS_TO_FILE_EX Reply

This message returns the result of the
FSCTL_DUPLICATE_EXTENTS_TO_FILE_EX
request<span id="Appendix_A_Target_22"
class="anchor"></span>[\<22\>](#Appendix_A_22).

The only data item this message returns is a status code, as specified
in section [2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon
success, the status code returned by the function that processes this
FSCTL SHOULD be STATUS_SUCCESS. The most common error codes are listed
in the following table.
