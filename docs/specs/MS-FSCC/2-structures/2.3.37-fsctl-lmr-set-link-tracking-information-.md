### 2.3.37 FSCTL_LMR_SET_LINK_TRACKING_INFORMATION Request

The FSCTL_LMR_SET_LINK_TRACKING_INFORMATION request message sets
[**Distributed Link Tracking
(DLT)**](#gt_5c3cacdf-4505-454f-a359-653e71415be0) information such as
file system type, [**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c)
ID, object ID, and destination computer's [**NetBIOS
name**](#gt_0334e0bd-2755-42f6-aeff-2d4a22bf4abf) for the file or
directory associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked. For
more information about Distributed Link Tracking (DLT), see
[\[MS-DLTW\]](%5bMS-DLTW%5d.pdf#Section_fc649f0e871a431a88b5d5b2f80e9cc9)
section 3.1.6.

There are two variations of this request, depending on whether it is
embedded within
[\[MS-SMB\]](%5bMS-SMB%5d.pdf#Section_f210069c70864dc2885e861d837df688)
or
[\[MS-SMB2\]](%5bMS-SMB2%5d.pdf#Section_5606ad475ee0437a817e70c366052962).
The request definitions are as follows.

- [FSCTL_LMR_SET_LINK_TRACKING_INFORMATION Request for
  SMB](#Section_e688ad9537e94d58bb7624c5e6d96de1)

- [FSCTL_LMR_SET_LINK_TRACKING_INFORMATION Request for
  SMB2](#Section_a6a5985e913142f7aa521792967944f4)

**Type (4 bytes):** An unsigned 32-bit integer that indicates the type
of file system on which the file is hosted on the destination computer.
MUST be one of the following.

| Value | Meaning |
|----|----|
| 0x00000000 | The destination file system is NTFS. |
| 0x00000001 | The destination file system is DFS. For more information, see [\[MSDFS\]](https://go.microsoft.com/fwlink/?LinkId=89945). |

**VolumeId (16 bytes):** A 16-byte
[**GUID**](#gt_f49694cc-c350-462d-ab8e-816f0103c6c1) that uniquely
identifies the [**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c)
for the object, as obtained from the **ObjectId** field of
[FileFsObjectIdInformation](#Section_dbf535ae315a45088bc584276ea106d4).

**ObjectId (16 bytes):** A 16-byte GUID that uniquely identifies the
destination file or directory within the volume on which it resides, as
indicated by **VolumeId**.

**NetBIOSName (variable):** A null-terminated ASCII string containing
the [**NetBIOS name**](#gt_0334e0bd-2755-42f6-aeff-2d4a22bf4abf) of the
destination computer, if known. For more information, see
[\[MS-DLTW\]](%5bMS-DLTW%5d.pdf#Section_fc649f0e871a431a88b5d5b2f80e9cc9)
section 3.1.6. If not known, this field is zero length and contains
nothing.
