### 2.4.13 FileEaInformation

This information class is used to query for the size of the extended
attributes (EA) for a file. An extended attribute is a piece of
application-specific metadata that an application can link with a file
that is not part of the file's data. For more information about extended
attributes, see
[\[MS-CIFS\]](%5bMS-CIFS%5d.pdf#Section_d416ff7cc536406ea9514f04b2fd1d2b)
section 2.2.1.2.

A **FILE_EA_INFORMATION** data element, defined as follows, is returned
by the server.

**EaSize (4 bytes):** A 32-bit unsigned integer that contains the
combined length, in bytes, of the extended attributes (EA) for the file.

This operation returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this file
information class is STATUS_SUCCESS. The most common error codes are
listed in the following table.
