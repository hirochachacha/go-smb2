### 2.3.20 FSCTL_GET_INTEGRITY_INFORMATION Reply

The FSCTL_GET_INTEGRITY_INFORMATION Reply message returns the results of
the [FSCTL_GET_INTEGRITY_INFORMATION
Request (section 2.3.19)](#Section_71b7a0a38f0c414cb4f8da9b957e56bc) and
indicates the current integrity state of the file or directory.

The **FSCTL_GET_INTEGRITY_INFORMATION_BUFFER** data element is as
follows.

**Reserved (2 bytes):** A 16-bit reserved value. This field MUST be set
to 0x0000 and MUST be ignored.

**Flags (4 bytes):** A 32-bit unsigned integer that contains zero or
more of the following flag values. Flag values not specified in the
following table SHOULD be set to 0 and MUST be ignored.

<p>0x00000001</p></td>
<td>Indicates that checksum enforcement is not currently enabled on the
target file.</td>

**ChecksumChunkSizeInBytes (4 bytes):** A 32-bit unsigned integer
specifying the size in bytes of each chunk in a
[**stream**](#gt_f3529cd8-50da-4f36-aa0b-66af455edbb6) that is
configured with integrity.

**ClusterSizeInBytes (4 bytes):** A 32-bit unsigned integer specifying
the size of a [**cluster**](#gt_feef37b3-c173-4f51-aab6-b55a6366259b)
for this volume in bytes.

This message also returns a status code, as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) MUST be
STATUS_SUCCESS or one of the following.
