### 2.3.21 FSCTL_GET_NTFS_VOLUME_DATA Request

This message requests that the server return information about the
[**NTFS**](#gt_86f79a17-c0be-4937-8660-0cf6ce5ddc1a) file system
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) that contains the
file or directory that is associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked.

This message does not contain any parameters.
