### 2.4.6 FileAttributeTagInformation

[**tag**](#gt_bfa52023-7248-4ab5-b889-6b53348a773b) information for a
file.

**FileAttributes (4 bytes):** A 32-bit unsigned integer that contains
the file attributes. Valid file attributes are as specified in section
[2.6](#Section_ca28ec38f155476881d64bfeb8586fc9).

**ReparseTag (4 bytes):** A 32-bit unsigned integer that specifies the
[**reparse point tag**](#gt_0be8a9c1-34d6-4632-b430-c5cf4ecc38a7). If
the **FileAttributes** member includes the FILE_ATTRIBUTE_REPARSE_POINT
attribute flag, this member specifies the reparse tag. Otherwise, this
member SHOULD be set to 0, and MUST be ignored. Section
[2.1.2.1](#Section_c8e77b3739094fe6a4ea2b9d423b1ee4) contains more
details on reparse tags.

This operation returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this file
information class is STATUS_SUCCESS. The most common error codes are
listed in the following table.
