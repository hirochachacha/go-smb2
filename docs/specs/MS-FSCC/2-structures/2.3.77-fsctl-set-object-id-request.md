### 2.3.77 FSCTL_SET_OBJECT_ID Request

This message sets the [**object
identifier**](#gt_aaaf2f1a-0b0a-487e-a0f0-c3510a6091b2) for the file or
directory associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked. The
message contains a
[FILE_OBJECTID_BUFFER (section 2.1.3)](#Section_5982df014b944feba6cd26a5eeaa9880)
data element. Either a Type 1 or a Type 2 buffer is
valid.<span id="Appendix_A_Target_77"
