### 2.3.36 FSCTL_IS_PATHNAME_VALID Reply

This message returns the results of the [FSCTL_IS_PATHNAME_VALID
Request (section 2.3.35)](#Section_38b85b3bed6d4a9ca83bb29f1684ba0b).

A STATUS_SUCCESS from this call means that the pathname is valid. An
error means that the pathname is not
valid.<span id="Appendix_A_Target_34"
