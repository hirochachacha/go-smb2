### 2.3.72 FSCTL_SET_ENCRYPTION Reply

This message returns the results of the FSCTL_SET_ENCRYPTION request. If
the file system of the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) containing the
specified file or directory does not support encryption, the request
MUST NOT succeed. The error code returned in this situation varies,
depending on the file system.

This message returns a status code, as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7), as well as a
[DECRYPTION_STATUS_BUFFER (section 2.3.72.1)](#Section_d02aafb50a9a4d35999063cc4a109849)
if an output buffer is passed in.

Upon success, the status code returned by the function that processes
this [**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is
STATUS_SUCCESS<span id="Appendix_A_Target_71"
class="anchor"></span>[\<71\>](#Appendix_A_71). The most common error
codes are listed in the following table.
