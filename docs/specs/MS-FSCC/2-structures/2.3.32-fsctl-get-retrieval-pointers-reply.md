### 2.3.32 FSCTL_GET_RETRIEVAL_POINTERS Reply

The FSCTL_GET_RETRIEVAL_POINTERS reply message returns the results of
the [FSCTL_GET_RETRIEVAL_POINTERS
request](#Section_8e4688cb0bbe4a2895edb1c763d86193) as a variably sized
data element, RETRIEVAL_POINTERS_BUFFER, that specifies the allocation
and location on disk of a specific file.

The FSCTL_GET_RETRIEVAL_POINTERS reply returns the extent locations
(that is, locations of allocated regions of disk space) of nonresident
data. A file system MAY allow resident data, which is data that can be
written to disk within the file's directory record. Because resident
data requires no additional disk space allocation, no extent locations
are associated with resident data.<span id="Appendix_A_Target_31"
class="anchor"></span>[\<31\>](#Appendix_A_31)

**ExtentCount (4 bytes):** A 32-bit unsigned integer that contains the
number of [EXTENTS](#Section_707cdf5a9d5f4a40ae88fb7331d1aa33) data
elements in the **Extents** array. This number can be zero if there are
no [**clusters**](#gt_feef37b3-c173-4f51-aab6-b55a6366259b) allocated at
(or beyond) the specified **StartingVcn**.

**Unused (4 bytes):** Reserved for alignment. This field can contain any
value and MUST be ignored.

**StartingVcn (8 bytes):** A 64-bit signed integer that contains the
starting [**virtual cluster number
(VCN)**](#gt_a80257f7-33b1-45d6-aafc-36ecdd5e11ae) returned by the
FSCTL_GET_RETRIEVAL_POINTERS reply. This is not necessarily the VCN
requested by the FSCTL_GET_RETRIEVAL_POINTERS request, as the file
system driver might return the starting VCN of the extent containing the
requested starting VCN. This value MUST be greater than or equal to 0.

**Extents (variable):** An array of zero or more EXTENTS data elements.
For the number of EXTENTS data elements in the array, see
**ExtentCount**.

**NextVcn (8 bytes):** A 64-bit signed integer that contains the
[**VCN**](#gt_a80257f7-33b1-45d6-aafc-36ecdd5e11ae) at which the next
extent begins. This value minus either **StartingVcn** (for the first
**Extents** array element) or the **NextVcn** of the previous element of
the array (for all other **Extents** array elements) is the length in
[**clusters**](#gt_feef37b3-c173-4f51-aab6-b55a6366259b) of the current
extent.

**Lcn (8 bytes):** A 64-bit signed integer that contains the [**logical
cluster number (LCN)**](#gt_a33da7f8-78bf-41a4-a4c0-a1d4caafa456) at
which the current extent begins on the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c). A 64-bit value
of -1 indicates either a [**compression
unit**](#gt_ce0d64e7-0847-4910-9611-b3044f3aae2d) that is partially
allocated or an unallocated region of a [**sparse
file**](#gt_57c7faf0-6002-4b1a-b8fc-fc9244d5a6e5). For more information
about sparse files, see
[\[SPARSE\]](https://go.microsoft.com/fwlink/?LinkId=90527). Compression
is performed in 16-cluster units. If a given 16-cluster unit compresses
to fit in, for example, 9 clusters, there will be a 7-cluster extent of
the file with an LCN of -1.

This message also returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is STATUS_SUCCESS.
