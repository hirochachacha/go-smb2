### 2.3.92 FSCTL_WRITE_USN_CLOSE_RECORD Request

This message requests that the server generate a record in the server's
file system change journal
[**stream**](#gt_f3529cd8-50da-4f36-aa0b-66af455edbb6) for the file or
directory associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked,
indicating that the file or directory was closed. This FSCTL can be
called independently of the actual file close operation to write a
[**USN**](#gt_01936446-8739-4b98-b83f-fb5e2a53ce4c) record and cause a
post of any pending USN updates for the indicated file.

No data structure is associated with this request.
