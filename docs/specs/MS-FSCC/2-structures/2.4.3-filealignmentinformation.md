the underlying device.

**AlignmentRequirement (4 bytes):** A 32-bit unsigned integer that MUST
contain one of the following values.

<td><p>FILE_BYTE_ALIGNMENT</p>
<p>0x00000000</p></td>
<td>Specifies that there are no alignment requirements for the

<tr>
<td><p>FILE_WORD_ALIGNMENT</p>

status code returned by the function that processes this file
information class is STATUS_SUCCESS. The most common error codes are
listed in the following table.
