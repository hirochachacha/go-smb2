### 2.3.76 FSCTL_SET_INTEGRITY_INFORMATION_EX Reply

This message returns the results of the
FSCTL_SET_INTEGRITY_INFORMATION_EX Request (section
[2.3.75](#Section_e11a4bed4445494990b0d3bdbae36218)).

The only data item this message returns is a status code, as specified
in section [2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon
success, the status code returned by the function that processes this
**FSCTL** is STATUS_SUCCESS. The most common error codes are listed in
the following table.
