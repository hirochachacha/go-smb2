### 2.3.61 FSCTL_READ_FILE_USN_DATA Request

This message requests that the server return the most recent change
journal [**USN**](#gt_01936446-8739-4b98-b83f-fb5e2a53ce4c) for the file
or directory associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked. This
message contains an optional READ_FILE_USN_DATA data
element.<span id="Appendix_A_Target_56"
class="anchor"></span>[\<56\>](#Appendix_A_56)
