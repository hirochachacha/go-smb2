### 2.3.80 FSCTL_SET_OBJECT_ID_EXTENDED Reply

This message returns the results of the [FSCTL_SET_OBJECT_ID_EXTENDED
request](#Section_757bc8faf24f44cf86dcadb2c113589d).

If the file system of the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) containing the
specified file or directory does not support the use of ObjectIds, the
request will not succeed. The error code returned in this situation
varies, depending on the file system.

The only data item this message returns is a status code, as specified
in section [2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon
success, the status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is STATUS_SUCCESS.
