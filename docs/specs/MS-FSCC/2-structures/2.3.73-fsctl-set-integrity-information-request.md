### 2.3.73 FSCTL_SET_INTEGRITY_INFORMATION Request

The FSCTL_SET_INTEGRITY_INFORMATION Request message requests that the
server set the integrity state of the file or directory associated with
the handle on which this FSCTL was
invoked.<span id="Appendix_A_Target_75"
class="anchor"></span>[\<75\>](#Appendix_A_75)

If the file system of the volume containing the specified file or
directory does not support integrity, the request MUST NOT succeed. The
error code returned in this situation is specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7).

to one of the following standard values.

Note that for **ReFS v2** any value except CHECKSUM_TYPE_NONE or
CHECKSUM_TYPE_UNCHANGED will set the integrity value to a
file-system-selected integrity mechanism and is not guaranteed to use
the user specified checksum value.

**Reserved (2 bytes):** A 16-bit reserved value. This field MUST be set
to zero and MUST be ignored.

**Flags (4 bytes):** A 32-bit unsigned integer that contains zero or
more of the following flag values. Flag values that are unspecified in
the following table SHOULD be set to 0 and MUST be ignored.
