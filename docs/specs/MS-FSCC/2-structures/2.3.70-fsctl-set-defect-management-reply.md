### 2.3.70 FSCTL_SET_DEFECT_MANAGEMENT Reply

The only data item this message returns is a status code, as specified
in section [2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon
success, the status code returned directly by the function that
processes this [**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is
STATUS_SUCCESS. The most common error codes are listed in the following
table.
