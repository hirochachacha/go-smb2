## 2.4 File Information Classes

File information classes are numerical values (specified by the Level
column in the following table) that specify what information for a file
is to be queried or set or for local use<span id="Appendix_A_Target_87"
class="anchor"></span>[\<87\>](#Appendix_A_87). File information classes
can require additional information to be included in the query or the
response. When appropriate, the additional information is detailed in
the file information class description. The table indicates which file
