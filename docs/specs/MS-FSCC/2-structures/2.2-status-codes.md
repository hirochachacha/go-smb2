## 2.2 Status Codes

This specification uses NTSTATUS status codes, as specified in
[\[MS-ERREF\]](%5bMS-ERREF%5d.pdf#Section_1bc92ddfb79e413cbbaa99a5281a6c90)
section 2.3. The format of a status code MUST be as specified in
\[MS-ERREF\].

The reply message lists the common error codes that are directly
generated by the function. Error codes can also be generated by code
below the file system (such as RAID drivers or disk drivers) or above
the file system (such as virus scanners).

A server SHOULD return a status of STATUS_INVALID_DEVICE_REQUEST when a
message is not supported remotely or is not supported on the file system
on which the file or directory handle specified
exists.<span id="Appendix_A_Target_14"
class="anchor"></span>[\<14\>](#Appendix_A_14)<span id="Appendix_A_Target_15"
class="anchor"></span>[\<15\>](#Appendix_A_15)

STATUS_BUFFER_OVERFLOW is a warning code and not an error code. This
warning means that the given output buffer is not large enough to
contain all of the requested information. Unless otherwise noted, a
given operation SHOULD attempt to return as much data as it reasonably
can.
