## 2.5 File System Information Classes

File system information classes are numerical values (specified by the
Level column in the following table) that specify what information on a
particular instance of a file system on a
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) is to be queried.
File system information classes can retrieve information such as the
file system type, volume label, size of the file system, and name of the
driver used to access the file system. The table indicates which file
system information classes are supported for query and set
operations.<span id="Appendix_A_Target_158"
class="anchor"></span>[\<158\>](#Appendix_A_158)

| File system information class | Level | Uses |
|----|----|----|
| [FileFsVolumeInformation](#Section_bf691378c34e4a13976e404ea1a87738) | 1 | Query |
| [FileFsLabelInformation](#Section_d5ab2652a7fd46559b35ea02bd05c0d8) | 2 | LOCAL<span id="Appendix_A_Target_159" class="anchor"></span>[\<159\>](#Appendix_A_159) |
| [FileFsSizeInformation](#Section_e13e068ce3a74dd494fd3892b492e6e7) | 3 | Query |
| [FileFsDeviceInformation](#Section_616b66d5b3354e1c8f87b4a55e8d3e4a) | 4 | Query |
| [FileFsAttributeInformation](#Section_ebc7e6e546504e54b17ccf60f6fbeeaa) | 5 | Query |
| [FileFsControlInformation](#Section_e5a707387ee446d9a5f76644daa49a51) | 6 | Query, Set |
| [FileFsFullSizeInformation](#Section_63768db7901242098cca00781e7322f5) | 7 | Query |
| [FileFsObjectIdInformation](#Section_dbf535ae315a45088bc584276ea106d4) | 8 | Query, Set |
| [FileFsDriverPathInformation](#Section_c530e7694b8744f4a188b9af8305eee0) | 9 | LOCAL<span id="Appendix_A_Target_160" class="anchor"></span>[\<160\>](#Appendix_A_160) |
| FileFsVolumeFlagsInformation | 10 | LOCAL<span id="Appendix_A_Target_161" class="anchor"></span>[\<161\>](#Appendix_A_161) |
| [FileFsSectorSizeInformation](#Section_3e75d97f1d0b4e47b43573c513837a57) | 11 | Query |

If an Information Class is specified that does not match the usage in
the above table, STATUS_INVALID_INFO_CLASS MUST be returned. If a file
system does not implement one of the above defined uses of an
Information Class, STATUS_INVALID_PARAMETER MUST be returned.
