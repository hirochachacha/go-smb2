### 2.5.3 FileFsDriverPathInformation

This information class is used locally to query if a given driver is in
the I/O path for a file system
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c).

A **FILE_FS_DRIVER_PATH_INFORMATION** data element, defined as follows,
is returned to the caller.

**DriverInPath (1 byte):** A [Boolean (section
2.1.8)](#Section_8ce7b38cd3cc415dab39944000ea77ff) value. Set to TRUE if
the driver is in the I/O path for the file system volume; set to FALSE
otherwise.

**Reserved (3 bytes):** Reserved for alignment. This field can contain
any value and MUST be ignored.

**DriverNameLength (4 bytes):** A 32-bit unsigned integer that contains
the length of the **DriverName** string.

**DriverName (variable):** A variable-length Unicode field containing
the name of the driver for which to query. This sequence of Unicode
characters MUST NOT be null-terminated.

This operation returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this file system
information class is STATUS_SUCCESS. The most common error codes are
listed in the following table.
