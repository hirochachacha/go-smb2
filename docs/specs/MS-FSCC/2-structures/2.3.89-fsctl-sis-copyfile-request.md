### 2.3.89 FSCTL_SIS_COPYFILE Request

The FSCTL_SIS_COPYFILE request message requests that the server use the
[**single-instance storage
(SIS)**](#gt_40c57198-06d7-4dcb-a011-d8152b64d2cb)
[**filter**](#gt_ffbe7b55-8e84-4f41-a18d-fc29191a4cda) to copy a file.
The message contains an SI_COPYFILE data element.

If the SIS filter is installed on the server, it will attempt to copy
the specified source file to the specified destination file by creating
an SIS link instead of actually copying the file data. If necessary and
allowed, the source file is placed under SIS control before the
destination file is created.

This [**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) can be issued
against either a file or directory handle. The source and destination
files MUST reside on the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) associated with
the given handle.

**SourceFileNameLength (4 bytes):** A 32-bit unsigned integer that
contains the size, in bytes, of the **SourceFileName** element,
including a terminating-Unicode null character.

**DestinationFileNameLength (4 bytes):** A 32-bit unsigned integer that
contains the size, in bytes, of the **DestinationFileName** element,
including a terminating-Unicode null character.

**Flags (4 bytes):** A 32-bit unsigned integer that contains zero or
more of the following flag values. Flag values not specified in the
following table SHOULD be set to 0 and MUST be ignored.
