### 2.3.19 FSCTL_GET_INTEGRITY_INFORMATION Request

The FSCTL_GET_INTEGRITY_INFORMATION Request message requests that the
server return the current integrity state of the file or directory
associated with the handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is
invoked.<span id="Appendix_A_Target_28"
class="anchor"></span>[\<28\>](#Appendix_A_28)

If the file system of the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) containing the
specified file or directory does not support the use of integrity, the
request will not succeed. The error code returned in this situation
varies, depending on the file system.

This message does not contain additional data elements.
