### 2.4.37 FilePipeInformation

This information class is used to query or set information on a named
pipe that is not specific to one end of the pipe or another.

A **FILE_PIPE_INFORMATION** data element, defined as follows, is
returned by the server or provided by the client.

**ReadMode (4 bytes):** A 32-bit unsigned integer that MUST contain one
of the following values.

<table style="width:97%;">
<colgroup>
<col style="width: 31%" />
<col style="width: 66%" />
</colgroup>
<thead>
<tr>
<th>Value</th>
<th>Meaning</th>
</tr>
</thead>
<tbody>
<tr>
<td><p>FILE_PIPE_BYTE_STREAM_MODE</p>
<p>0x00000000</p></td>
<td>If this value is specified, data MUST be read from the pipe as a
stream of bytes.</td>
</tr>
<tr>
<td><p>FILE_PIPE_MESSAGE_MODE</p>
<p>0x00000001</p></td>
<td>If this value is specified, data MUST be read from the pipe as a
stream of messages.</td>
</tr>
</tbody>
</table>

If this field is set to FILE_PIPE_BYTE_STREAM_MODE, any attempt to
subsequently change it MUST fail with a STATUS_INVALID_PARAMETER error
code.

**CompletionMode (4 bytes):** A 32-bit unsigned integer that MUST
contain one of the following values.

<table style="width:97%;">
<colgroup>
<col style="width: 32%" />
<col style="width: 64%" />
</colgroup>
<thead>
<tr>
<th>Value</th>
<th>Meaning</th>
</tr>
</thead>
<tbody>
<tr>
<td><p>FILE_PIPE_QUEUE_OPERATION</p>
<p>0x00000000</p></td>
<td>If this value is specified, blocking mode MUST be enabled. When the
pipe is being connected, read to, or written from, the operation is not
completed until there is data to read, all data is written, or a client
is connected. Use of this mode can result in the server waiting
indefinitely for a client process to perform an action.</td>
</tr>
<tr>
<td><p>FILE_PIPE_COMPLETE_OPERATION</p>
<p>0x00000001</p></td>
<td>If this value is specified, non-blocking mode MUST be enabled. When
the pipe is being connected, read to, or written from, the operation
completes immediately.</td>
</tr>
</tbody>
</table>

This operation returns a status code as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this file
information class is STATUS_SUCCESS. The most common error codes are
listed in the following table.

<td><p>STATUS_INFO_LENGTH_MISMATCH</p>
<p>0xC0000004</p></td>
<td>The specified information record length does not match the length
that is required for the specified information class.</td>
</tr>
<tr>
<td><p>STATUS_INVALID_PARAMETER</p>
<p>0xC000000D</p></td>
<td><p>An invalid parameter was passed to a service or function. When
setting the FilePipeInformation information level,
STATUS_INVALID_PARAMETER will be returned:</p>
<ul>
<li><p>If the <strong>ReadMode</strong> field is set to
FILE_PIPE_BYTE_STREAM_MODE and a subsequent set operation attempts to
set the <strong>ReadMode</strong> field to any value other than
FILE_PIPE_BYTE_STREAM_MODE.</p></li>
<li><p>If the value of the <strong>ReadMode</strong> field is not equal
to FILE_PIPE_MESSAGE_MODE or FILE_PIPE_BYTE_STREAM_MODE.</p></li>
<li><p>If the value of the <strong>CompletionMode</strong> field is not
equal to FILE_PIPE_QUEUE_OPERATION or
FILE_PIPE_COMPLETE_OPERATION.</p></li>
</ul></td>
</tr>
