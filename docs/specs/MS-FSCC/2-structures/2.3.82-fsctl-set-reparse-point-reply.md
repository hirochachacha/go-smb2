### 2.3.82 FSCTL_SET_REPARSE_POINT Reply

This message returns the results of the [FSCTL_SET_REPARSE_POINT
request](#Section_4dc2b168f1774eeca14b25a51cbba2cf).

If the file system of the
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) containing the
specified file or directory does not support [**reparse
points**](#gt_4fed0b53-5fc8-4818-886f-93d87f3035e1), the request will
not succeed. The error code returned in this situation varies, depending
on the file system.

The only data item this message returns is a status code, as specified
in section [2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon
success, the status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is STATUS_SUCCESS.
