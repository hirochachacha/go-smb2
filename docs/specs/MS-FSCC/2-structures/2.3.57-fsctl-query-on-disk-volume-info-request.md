### 2.3.57 FSCTL_QUERY_ON_DISK_VOLUME_INFO Request

This message requests UDF-specific
[**volume**](#gt_9a876829-33a1-4f0b-8b81-8552b7e5561c) information for
the volume that contains the file or directory associated with the
handle on which this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) was invoked.

This message does not contain any additional data elements.

This FSCTL is only valid on UDF file systems. All other File Systems
will treat this as an invalid FSCTL. For information regarding UDF, see
[\[UDF\]](https://go.microsoft.com/fwlink/?LinkId=184845).
