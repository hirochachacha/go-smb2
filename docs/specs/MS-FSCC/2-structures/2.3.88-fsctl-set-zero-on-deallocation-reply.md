### 2.3.88 FSCTL_SET_ZERO_ON_DEALLOCATION Reply

This message returns the results of the [FSCTL_SET_ZERO_ON_DEALLOCATION
request](#Section_e919ce3db6ab40c6a48e2c613911a5cf). The only data item
this message returns is a status code, as specified in section
[2.2](#Section_a7527db8cbfe4f2aabc3133bf5160bd7). Upon success, the
status code returned by the function that processes this
[**FSCTL**](#gt_4ffb96a7-5fad-488e-9438-b7707d2e4226) is STATUS_SUCCESS.
