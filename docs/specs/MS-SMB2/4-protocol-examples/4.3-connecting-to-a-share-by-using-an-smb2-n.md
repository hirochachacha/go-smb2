    the **Dialects** array.

    equal to STATUS_MORE_PROCESSING_REQUIRED and the response containing
    the output token from GSS.

7.  The client completes the authentication and sends an [SMB2
    TREE_CONNECT Request](#Section_832d213022e84afbaafdb30bb0901798)

    [**tree connect**](#gt_c65d1989-3473-4fa9-ac45-6522573823e3) request

    [**Unicode**](#gt_c305d0ab-8b94-461a-bd76-13b40cb8c4d8)
    [**share**](#gt_a49a79ea-dac7-4016-9a84-cf87161db7e3) name
    "\\smb2server\IPC\$".
