#### 3.3.4.22 Server Application Enables the SMB2 Server

The server MUST verify that the caller of this interface is the server
service
[\[MS-SRVS\]](%5bMS-SRVS%5d.pdf#Section_accf23b00f57441c918543041f1b0ee9),
in an implementation-specific manner.  In this case only,
**ServerEnabled** MUST be set to TRUE.
