### 3.3.5 Processing Events and Sequencing Rules

The SMB 2 Protocol server is driven by a series of request messages sent
by the client. Processing for these messages is determined by the
command in the [SMB2 header](#Section_5cd6452260b34f3ea157fe66f1228052)
of the response and is detailed for each of the SMB2 response messages
below.
