#### 3.3.4.16 Server Application Requests Querying a Share

The calling application provides tuple \<ServerName, ShareName\> of the
share that is being queried. The server MUST look up the Share in
**ShareList** where **ServerName** matches **Share.ServerName** and
**ShareName** matches **Share.Name**. If the matching Share is found,
the server MUST return a share in SHARE_INFO_503_I structure and
SHARE_INFO_1005 structure with the following values set and return
STATUS_SUCCESS to the calling application; otherwise the server MUST
return an implementation-dependent error.
