#### 3.3.4.9 DFS Server Notifies SMB2 Server That a Share Is a DFS Share

In response to this event, the SMB2 server MUST set the **Share.IsDfs**
attribute of the [**share**](#gt_a49a79ea-dac7-4016-9a84-cf87161db7e3)
specified in section
[3.3.1.6](#Section_6fe086cf40ad49d893c514b8c8a7b2d9). When a
[**DFS**](#gt_0b8086c9-d025-45b8-bf09-6b5eca72713e) server running on
this computer claims a share as a DFS share, it MUST notify the SMB2
server via this event.
