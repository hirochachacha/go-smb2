#### 3.1.5.2 Calculating the CreditCharge

The CreditCharge of an SMB2 operation is computed from the payload size
(the size of the data within the variable-length field of the request)
or the maximum size of the response.

1.  CreditCharge = (max(SendPayloadSize, Expected ResponsePayloadSize)
    – 1) / 65536 + 1
