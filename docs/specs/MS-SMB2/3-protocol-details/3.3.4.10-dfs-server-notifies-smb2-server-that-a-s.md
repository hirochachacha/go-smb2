#### 3.3.4.10 DFS Server Notifies SMB2 Server That a Share Is Not a DFS Share

In response to this event, the SMB2 server MUST clear the
**Share.IsDfs** attribute of the
[**share**](#gt_a49a79ea-dac7-4016-9a84-cf87161db7e3) specified in
section [3.3.1.6](#Section_6fe086cf40ad49d893c514b8c8a7b2d9).
