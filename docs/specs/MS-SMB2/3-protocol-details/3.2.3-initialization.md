### 3.2.3 Initialization

**ConnectionTable**: MUST be set to an empty table.

**RejectGuestAccess**: MUST be set to an implementation-specific
value.<span id="Appendix_A_Target_106"
class="anchor"></span>[\<106\>](#Appendix_A_106)

**AllowInsecureGuestAccess**: MUST be set to an implementation-specific
value.<span id="Appendix_A_Target_107"
class="anchor"></span>[\<107\>](#Appendix_A_107)

If the client implements the SMB 2.1 dialect or SMB 3.x dialect family:

**GlobalFileTable**: If implemented, MUST be set to an empty table.

**ClientGuid**: MUST be set to a newly generated GUID.

If the client implements SMB 3.x dialect family:

**MaxDialect**: MUST be set to the highest SMB2 dialect that the client
implements.

**RequireSecureNegotiate**: MUST be set based on the local configuration
policy.<span id="Appendix_A_Target_108"
class="anchor"></span>[\<108\>](#Appendix_A_108)

**ServerList**: MUST be set to empty.

**ShareList**: MUST be set to an empty list.

If the client implements the SMB 3.1.1 dialect:

**CompressAllRequests** MUST be set based on the local configuration
policy.<span id="Appendix_A_Target_109"
class="anchor"></span>[\<109\>](#Appendix_A_109)

**IsMutualAuthOverQUICSupported** MUST be set in an
implementation-specific manner.<span id="Appendix_A_Target_110"
class="anchor"></span>[\<110\>](#Appendix_A_110)

**ClientCertificateMappingTable** MUST be initialized based on the
administrator configuration.
