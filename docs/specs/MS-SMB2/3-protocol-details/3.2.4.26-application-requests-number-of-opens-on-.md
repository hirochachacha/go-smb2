#### 3.2.4.26 Application Requests Number of Opens on a Tree Connect

The application provides a handle to the **TreeConnect** representing
the share to be queried.

The client MUST determine the total number of opens on the
**TreeConnect** by enumerating the **Opens** in
**TreeConnect.Session.Connection.OpenTable** and counting those
**Opens** where **Open.TreeConnect** matches the **TreeConnect**. The
resulting count is returned to the calling application.
