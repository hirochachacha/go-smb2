#### 3.3.4.8 DFS Server Notifies SMB2 Server That DFS Is Active

In response to this event, the SMB2 server MUST set the global state
variable **IsDfsCapable** to TRUE. If the
[**DFS**](#gt_0b8086c9-d025-45b8-bf09-6b5eca72713e) server is running on
this computer, it MUST notify the SMB2 server that the DFS capability is
available via this event.
