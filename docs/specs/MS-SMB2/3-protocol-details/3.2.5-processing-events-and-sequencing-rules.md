### 3.2.5 Processing Events and Sequencing Rules

The SMB 2 Protocol client is driven by a series of response messages
that are sent by the server. Processing for these messages is determined
by the command in the [SMB2
header](#Section_5cd6452260b34f3ea157fe66f1228052) of the response and
is detailed for each of the SMB2 response messages in the sections that
follow.
